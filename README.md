## 💻 Programs

This repository contains practical programs based on fundamental C++ programming and Object-Oriented Programming concepts including variables, data types, decision-making, loops, arrays, functions, classes, constructors, static members, inline functions, and friend functions.

### 01. Basic Data Types

Demonstrates the use of basic C++ data types such as integer, character, and floating-point variables and displays their values.

### 02. Conditional Statement

Demonstrates the use of an `if-else` statement to check whether a student's marks are sufficient to pass.

### 03. Array and Loop

Demonstrates the use of an array to store marks and a `for` loop to display the elements of the array.

### 04. Function with Parameters

Demonstrates the declaration, definition, and calling of a function to calculate the sum of two numbers.

### 05. Class and Object

Demonstrates the creation of a class and object in C++. The program stores and displays student details such as name and age.

### 06. Constructor and Destructor

Demonstrates the use of a constructor and destructor in a class. The constructor is called when an object is created and the destructor is called when the object is destroyed.

### 07. Static Data Member

Demonstrates the use of a static data member to count the number of objects created for a class.

### 08. Inline Function and Friend Function

Demonstrates the use of an inline member function and a friend function to access and display a private data member of a class.
